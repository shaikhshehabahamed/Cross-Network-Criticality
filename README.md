# Criticality Is Not Vulnerability: A Cross-Network Test of When Interpretable Centrality Fails in Supply Chain Risk Assessment

Recent work pairs graph neural networks (GNNs) with centrality metrics to identify critical or vulnerable supply chain nodes, but few studies validate conclusions across more than one independent real network, and none treat a firm's criticality (impact if it fails) and vulnerability (likelihood of being disrupted) as targets that need different predictive strategies. We simulate cascading failure under a single-sourcing (AND) rule on two independent real supply networks, AnonNet (7,245 firms) and SupplyChainKG (6,465 firms), to build ground-truth criticality and vulnerability scores. We then train five predictor families (degree, betweenness, PageRank, Katz, and k-core centrality; ridge regression; a GraphSAGE graph neural network) on one network and test each strictly out of sample on the other, in both directions, with paired bootstrap significance testing. Betweenness centrality alone outperforms both learned methods at recovering criticality out of network (Spearman correlation 0.44 to 0.72, versus 0.23 to 0.45 for the learned methods). For vulnerability, every centrality baseline is not just insufficient but significantly and reproducibly inverted (Spearman correlation −0.37 to −0.41 in both directions). Ridge regression, using only local topology, recovers vulnerability reliably (Spearman correlation 0.78 to 0.85) with far less cross-seed variance than the graph neural network. The mechanism is direct-supplier redundancy, not network position. We translate this asymmetry into an operational two-metric triage and quantify country- and industry-level exposure concentration in both networks.
